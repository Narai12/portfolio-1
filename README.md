# Narain Das — Professional IT Portfolio

A responsive personal portfolio website for a Software Engineering student at the University of Sindh, Jamshoro.

## Built with
- HTML5
- CSS3
- JavaScript

## Portfolio sections
- Home, About Me, Career Objective and Education
- Technical Skills and Areas of Interest
- Projects Portfolio and a Featured Project Case Study
- Academic Experience and Training
- Certifications and Achievements (truthfully marked as pending where not yet available)
- Resume / CV placeholder
- GitHub profile and Contact

## Run locally
1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

## Deployment
This repository is intended for Git-connected deployment through Vercel or Netlify. Configure the project as a static site and use the repository root as the publish directory.

## Notes
Project details and credentials are presented conservatively. Add verified project screenshots, a current CV PDF, and professional contact details before final submission. Do not add private credentials or API secrets.
